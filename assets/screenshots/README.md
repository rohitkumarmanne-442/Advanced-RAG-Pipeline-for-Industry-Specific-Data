# Screenshots

This directory contains screenshots of the web application for the README.

To capture screenshots:
1. Run `streamlit run app.py` locally
2. Execute a query (e.g., "What was the total revenue for FY2023?")
3. Take screenshots of:
   - `pipeline_flow.png` - The pipeline flow visualization + timing cards
   - `retrieval_comparison.png` - Dense vs Sparse tabs with score charts
   - `rrf_fusion.png` - The RRF breakdown table
   - `answer_generation.png` - The generated answer with context window
